# Posts

[しろみつ's Blog](https://blog.siro.3tsu.dev/)の投稿を置いているリポジトリです。

Gitのサブモジュールを利用して[`siro3tsu/blog-siro-3tsu-dev`](https://github.com/siro3tsu/blog-siro-3tsu-dev/)リポジトリに組み込んで記事としてレンダリングさせています。

## ディレクトリ構成

- `README.md`
このファイルです。`.md`ファイルはコンテンツコレクションから除外されているためレンダリング対象外です。
- `.markdownlint-cli2.jsonc`
VSCodeのmarkdownlint拡張機能の設定ファイルです。  
VSCodeでMDXをプレビューするにはMarkdownとしてファイルを関連付けないといけないため、markdownlintの警告が表示されてしまいます。  
この設定ファイルで.mdxファイルではmarkdownlintを無効化するように設定しています。
- `YYYY-MM-DD-Slug/`
投稿フォルダです。  
  - `README.mdx`  
  投稿本体の`.mdx`ファイルです。
  - その他画像等のアセットが入ります。

### 投稿フォルダ名について

- `YYYY`
4桁の西暦
- `MM`
0埋めして2桁にした月
- `DD`
0埋めして2桁にした日  
`YYYY-MM-DD` が投稿日として扱われます。
- `Slug`
投稿を識別するID的なもの

## フロントマターの構成

以下はフロントマターの例です。

```mdx
---
title: 'Git for Windowsのインストール手順'
updatedDate: 2026-08-20
author: 'siro3tsu'
tags: ['Git', 'Windows']
---
```

### 各項目について

- `title`
投稿タイトル（必須、文字列）
- `updatedDate`
更新日（オプション、日付）
- `author`
投稿者ID（必須、文字列）
- `tags`
タグ（必須、文字列の配列）
